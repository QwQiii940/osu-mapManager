# osu! Beatmap Library

一个面向 **osu! stable** 的本地谱面与收藏夹管理桌面应用。界面采用深色工作区、青色强调色和独立功能页面，参考 OPP 的导航与内容分区方式；核心数据解析和操作仍沿用经过验证的 Python 实现。

> 仅支持 osu! **stable**（`osu!.db` / `collection.db`），不兼容 osu!lazer。

---

## 功能特性

- **收藏夹管理**：新建 / 重命名 / 删除 / 排序（按名称、按数量）收藏夹；增删收藏夹内谱面；合并同名、批量删除、批量导出。
- **批量导入 / 导出**：把一个收藏夹内谱面批量导出为 `.osz`；也可把 `.osz` 批量导入并加入指定收藏夹。
- **多维条件筛选 + 批量操作**：按星级、AR / OD / CS / HP、BPM、模式、难度名、标题 / 艺术家 / 作者、长度等条件筛选；支持勾选多选后批量删除 / 移入收藏夹。
- **自动分类**：按艺术家 / 首字母 / 星级区间批量生成收藏夹；支持「重新整理」清空并重建，可指定目标数量与 BPM / 星级 / 模式条件。
- **艺术家别名归一化**：`Camellia` = `かめりあ` 等英文 / 日文 / 中文别名合并；多艺术家谱面（`A feat. B`、`1234 X 5678`）按著名度与歌曲数量归入一个艺术家，减少收藏夹数量（osu! 收藏夹存在约 250 个显示上限）。
- **本地星级计算**：用 rosu-pp-py（osu! 官方难度算法的 Rust 移植）补齐 `osu!.db` 中缺失的星级，让「按星级筛选 / 删除」覆盖全部谱面。
- **谱面预览「播放音频」**：在歌曲行直接播放 / 暂停音频（mp3 / ogg / wav / flac / m4a），带底部进度条与播放 / 停止按钮。
- **批量选择**：歌曲与收藏夹使用高对比复选框；全选 / 取消作用于筛选结果并跨分页保持状态。
- **体验优化**：删除移入回收站（可恢复）、删除确认开关、删除后保持界面位置与展开状态、缩略图 LRU 缓存、深色主题默认、自定义强调色、自定义背景图与透明度、后台线程避免卡顿。写回收藏夹数据库前会刷新 `.bak` 备份，并使用原子替换。

```
osu mapManager/

│   ├── pages/               # 应用壳、收藏夹、歌曲库、设置控制器

├── manager.py               # 收藏夹、歌曲、导入导出和删除业务
```

## 安装与运行

### 方式一：使用打包好的可执行文件

从 [Releases](../../releases) 下载 `OsuManager.exe`，双击运行即可（无需安装 Python）。

### 方式二：从源码运行

```powershell
# 1. 安装依赖（推荐使用虚拟环境）
pip install -r requirements.txt

# 2. 运行
python main.py
# 或双击 run.bat
```

首次启动会自动探测 `%LOCALAPPDATA%\osu!`；找不到时手动选择包含 `collection.db` / `osu!.db` 的目录即可。

## 界面说明

- **首页**：谱面集 / 难度 / 收藏夹数量概览与快捷入口。
- **收藏夹**：以文件夹图标网格展示，点击进入该收藏夹的歌曲列表；右上角可新建 / 自动分类 / 重新整理 / 批量删除 / 导出。
- **全部歌曲**：竖向列表展示所有谱面集，每行左侧复选框（多选）+ 缩略图 + 标题 / 播放按钮 + 信息（艺术家 · 星级 · AR / OD / BPM），右侧「收藏 / 删除」按钮；点击可展开各难度；支持搜索、分类、条件筛选、分页。
- **设置**：选择 osu! 目录、切换主题颜色、自定义强调色 / 背景图 / 透明度、重新读取歌曲文件、计算缺失星级、导入 `.osz`。

## osu! 文件格式要点

> 参考社区逆向工程：[osu-db (Rust)](https://github.com/kovaxis/osu-db)、`osu-database-reader` (C#)。

| 文件 / 目录 | 用途 | 格式 |
| --- | --- | --- |
| `osu!.db` | 全部已导入谱面的元数据缓存 | 私有二进制 |
| `collection.db` | 用户收藏夹及所含谱面 | 私有二进制 |
| `Songs/` | 每个谱面集一个子目录，含 `.osu` 与音频 / 图片 | 文件目录 |
| `.osu` | 单个难度的谱面定义 | 文本（INI 风格） |
| `.osz` | 谱面集压缩包 | ZIP（改名 `.osz`） |

关键细节：

- 所有多字节整数均为**小端序**；字符串首字节 `0x00` 表示空、`0x0b` 表示后跟 ULEB128 长度 + UTF-8 字节。
- 收藏夹通过 `.osu` 文件内容的 **MD5** 标识谱面（与 `osu!.db` 的 `hash` 一致）。
- 星级条目：`0x08` + u32 modset + `0x0c`/f32（版本 `>= 20250107`）或 `0x0d`/f64（更早）。
- Timing point：`f64 beat_length`（毫秒 / 拍）+ `f64 offset` + `bool not_inherited`；真实 BPM = `60000 / beat_length`（仅 `not_inherited` 为真时）。
- 格式历史分支（`>= 20140609`、`>= 20191106`、`>= 20250107`）已按版本号自动处理。

## 已知限制

- 仅支持 osu! **stable**，不兼容 osu!lazer（收藏夹存储于 Realm / SQLite）。
- 星级优先取自 `osu!.db`（官方值）；缺失时可用「设置 → 计算缺失星级」本地补齐，但只更新内存视图、不回写 `osu!.db`。
- 修改 `collection.db` 前请先退出 osu!，避免文件占用冲突。
- 本地计算星级依赖 rosu-pp-py 与谱面文件本身，个别无击打对象的模板谱面无法计算。
